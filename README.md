# TechFix Islamabad: Computer Repair and IT Support Website

**Course:** CSC-114 Introduction to ICT, Bahria University Islamabad (Fall 2026)
**Instructor:** Ms. Nadia Kalsoom
**Group:** FixStack

## Purpose
A multi-page website for TechFix Islamabad, a computer repair and IT support shop.
It lets customers see services, prices and opening hours, ask common questions,
estimate repair costs and send a repair request online.
